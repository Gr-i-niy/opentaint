# Build

Delegate build-project. Inputs: `<project-root>`, model-out `.opentaint/project`, the recorded `model_commit` (so it can tell a reusable model from a stale one — a null forces a rebuild), any build constraints (Java version, submodules, `--package` filters). Verify `.opentaint/project/project.yaml` exists, is non-empty, and — for a multi-module project — covers the expected module count, not just that the file is present. Set `phases.build: done` and record the commit the model was built from in `state.yaml`'s `model_commit` (`git rev-parse HEAD`, or null when the tree is untracked or dirty). When the existing model was reused unchanged, leave its `model_commit` as is.
